# ATLAS — Lunar Image Correspondence

> **Multi-modal, Sun-angle and scale-invariant image correspondence for Chandrayaan-2 optical imagery**

ATLAS is a computer-vision prototype for registering and finding correspondences between lunar images captured under different imaging conditions. The project is aimed at the **Chandrayaan-2 image correspondence / image registration problem**, where the same lunar surface region may appear significantly different because of illumination, viewpoint and scale changes.

The current repository contains an initial **SIFT + FLANN + geometric verification** baseline that establishes a classical feature-matching pipeline before moving toward more robust multi-modal and invariant correspondence methods.

---

## Problem

Lunar images acquired from different instruments or acquisition conditions are difficult to align reliably. The same terrain can change in appearance because of:

- ☀️ **Illumination variation** — different Sun angles and shadows
- 🔭 **Viewpoint variation** — changes in camera geometry and viewing direction
- 🔍 **Scale variation** — differences in image resolution and ground sampling
- 🛰️ **Multi-modal imagery** — different sensors can represent the same terrain differently

A useful correspondence system should identify geometrically consistent points even when simple pixel-level comparison fails.

---

## Current Approach

The present prototype uses a classical local-feature pipeline:

```text
Input Images
     │
     ▼
Grayscale Conversion
     │
     ▼
SIFT Feature Detection
     │
     ▼
SIFT Descriptors
     │
     ▼
FLANN KNN Matching
     │
     ▼
Lowe Ratio Test
     │
     ▼
Mutual / Cross-Check Matching
     │
     ▼
RANSAC Homography Estimation
     │
     ▼
Geometric Inlier Verification
     │
     ├── Match Statistics
     ├── Reprojection Error
     ├── Aligned Image
     ├── Alignment Overlay
     └── Difference Image
```

### Why this baseline?

SIFT provides scale-aware local descriptors and is a useful starting point for establishing whether meaningful geometric correspondence can be recovered from the input imagery. FLANN provides efficient descriptor matching, while mutual matching and RANSAC reduce unreliable correspondences.

This baseline is intentionally simple: it gives ATLAS a measurable reference point for evaluating more advanced methods later.

---

## Features

The current prototype performs:

- SIFT keypoint detection and descriptor extraction
- FLANN-based nearest-neighbour matching
- Lowe's ratio test
- Forward and backward matching
- Mutual correspondence filtering
- RANSAC-based homography estimation
- Inlier / outlier separation
- Reprojection-error analysis
- Image alignment using the estimated homography
- Alignment overlay generation
- Pixel-difference visualization
- Homography matrix export
- Keypoint and verified-match visualization

## Usage

Place the two images to be compared at:

```text
images/image1.jpg
images/image2.jpg
```

Then run:

```bash
python sift_match.py
```

The script creates the `outputs/` directory automatically and writes the generated registration and diagnostic results there.

## Output Metrics

ATLAS reports several useful measurements during matching:

| Metric | Purpose |
|---|---|
| Keypoints | Number of detected SIFT features in each image |
| Ratio-test matches | Matches surviving Lowe's ratio test |
| Mutual matches | Correspondences consistent in both directions |
| RANSAC inliers | Geometrically consistent correspondences |
| Inlier ratio | Fraction of candidate matches supported by the estimated geometry |
| Mean reprojection error | Average geometric error of inlier correspondences |
| Median reprojection error | Robust measure of correspondence accuracy |
| RMSE | Overall reprojection-error measure |

These metrics provide a starting point for comparing future correspondence approaches against the classical baseline.

## Research Direction

ATLAS is intended to evolve beyond conventional SIFT matching toward a system specifically designed for lunar, multi-modal imagery.

Planned areas include:

1. **Illumination robustness**
   - Sun-angle normalization
   - Shadow-aware preprocessing
   - Illumination-invariant representations

2. **Scale and viewpoint robustness**
   - Multi-scale feature extraction
   - Improved geometric models
   - Robust local and global correspondence verification

3. **Multi-modal correspondence**
   - Cross-sensor feature representations
   - Chandrayaan-2 OHRC / TMC / IIRS imagery
   - Modality-invariant descriptors

4. **Learning-based correspondence**
   - Deep local features
   - Learned feature matching
   - Transformer-based correspondence models
   - Self-supervised / domain-specific approaches

5. **Evaluation**
   - Quantitative registration benchmarks
   - Inlier ratio and reprojection-error comparisons
   - Robustness testing across illumination, scale and viewpoint changes

## Status

🚧 **Prototype / Research Baseline**

The current implementation is an experimental classical-computer-vision baseline. It is not yet the final ATLAS solution for multi-modal Chandrayaan-2 image registration.

The goal is to establish a reproducible baseline first, then progressively replace individual components with methods better suited to the lunar image-correspondence problem.

---

## Motivation

ATLAS is built around a simple research question:

> **Can reliable geometric correspondence be recovered between lunar observations of the same terrain despite major changes in illumination, viewpoint, scale and sensing modality?**

The project explores that question from a practical computer-vision perspective, starting with interpretable classical methods and moving toward more specialized approaches.
